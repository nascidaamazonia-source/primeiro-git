# Hermes AI Agent - Página de Serviços

Primeiro projeto em HTML, CSS e JavaScript.

## Sobre

Landing page para venda de serviços com Hermes AI Agent, incluindo:

- Hero com chamada principal
- Cards de serviços
- Benefícios
- Planos
- Formulário de contato
- Menu responsivo
- Interação simples com JavaScript

## Arquivos

- `index.html`: estrutura da página
- `style.css`: estilos visuais e responsividade
- `script.js`: interações do menu, simulação e formulário

## Como abrir

Abra o arquivo `index.html` no navegador.

No Windows, você pode abrir pelo Explorador de Arquivos ou usar:

```bash
explorer.exe index.html
```
